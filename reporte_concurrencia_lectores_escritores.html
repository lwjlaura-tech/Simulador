2. Lectores - Escritores

Varios lectores pueden consultar la base de datos al mismo tiempo, pero un escritor necesita acceso exclusivo. La sección crítica es la base de datos y la variable compartida num_lectores que cuenta cuántos lectores hay activos en cada instante.

Mecanismo de sincronización

Patrón Lightswitch con 2 Mutex: 'mutex_contador' protege el incremento y decremento de num_lectores, y 'acceso_bd' protege la base de datos. El primer lector (num_lectores == 1) toma acceso_bd para bloquear a los escritores; el último lector en salir (num_lectores == 0) lo libera.
